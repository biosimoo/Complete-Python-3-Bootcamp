## Patent Keyword Classifier

This repository includes `patent_keyword_classifier.py`, a script that fetches patent data from [Google Patents](https://patents.google.com/), extracts keywords, groups similar patents, and visualizes the result in two dimensions.

### Usage

```bash
python patent_keyword_classifier.py US1234567B1 US7654321B2 --clusters 4
```

### Note

Network access is required for the script to download patent information. If the environment lacks connectivity, fetching patents will fail.
